# CalculatorForm

Програма CalculatorForm — це проста Windows Forms-аплікація для приблизної оцінки викидів CO₂.

## Функціонал

- введення кількості поїздок на автомобілі;
- введення кількості годин використання електроприладів;
- автоматичний розрахунок приблизних викидів вуглекислого газу;
- відображення результату у кілограмах CO₂.

Для оцінки використовуються прості коефіцієнти:
- 1 поїздка на авто ≈ 4.5 кг CO₂;
- 1 година використання електроприладів ≈ 0.35 кг CO₂.

Результат показує загальну оцінку викидів на основі введених даних.
